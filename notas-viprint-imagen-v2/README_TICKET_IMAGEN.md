# Actualización ticket con marca IMAGEN

Esta actualización mantiene el ticket de ViPrint, pero cuando la nota pertenece a la empresa Imagen agrega una línea visible:

IMAGEN

Archivos a reemplazar en /public_html/notas-viprint-imagen-v2/:

- ticket_pago.php
- assets/js/qz-viprint.js

No ejecutar SQL.
No tocar config/database.php.

Después de subir los archivos, abrir el ticket y presionar Ctrl + F5.
