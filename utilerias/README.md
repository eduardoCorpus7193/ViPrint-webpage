# Menú de sistemas ViPrint

Menú sencillo para acceder a los sistemas internos de ViPrint Publicidad.

## Instalación

1. Sube la carpeta `menu-sistemas-viprint` dentro de `public_html` o renómbrala como prefieras.
2. Verifica que `index.php`, `assets/css/styles.css` y `assets/img/logo.png` conserven la misma estructura.
3. Abre la ruta correspondiente, por ejemplo:

   `https://viprint.com.mx/menu-sistemas-viprint/`

No requiere base de datos, configuración ni archivo `.htaccess`.

## Accesos incluidos

- Vacaciones
- Permisos de salida
- Horas extras
- Documentos de nómina

## Colores

- Rojo ViPrint: `#A92624`
- Fondo claro: `#F8F6F8`
